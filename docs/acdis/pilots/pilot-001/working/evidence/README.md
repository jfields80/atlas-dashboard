# Evidence Directory Rules

Store manually collected artifacts in this directory using:

<competitor-id>_<artifact-type>_<sequence>.<extension>

## Artifact type examples

- homepage
- category-page
- location-page
- listing-page
- pricing
- monetization
- screenshot
- saved-page
- pdf
- notes

## Example filenames

- comp-slot-01_homepage_001.html
- comp-slot-01_screenshot_001.png
- comp-slot-02_location-page_001.html
- comp-slot-03_pdf_001.pdf
- comp-slot-04_notes_001.md

## Evidence discipline

Every FACT entered into working/research_case.json must point to a real saved artifact, URL, screenshot, PDF, excerpt, or operator note collected during manual research.

Do not add FACT entries without a real source artifact.
Do not invent source references.

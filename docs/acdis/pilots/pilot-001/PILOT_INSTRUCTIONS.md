# Pilot 001 Instructions

This pilot is preparation only. Do not insert real competitor evidence yet.

## Workflow

1. Select one directory opportunity.
2. Identify three to five competitors manually.
3. Define four to eight comparison dimensions.
4. Record observations as FACT, INFERENCE, HYPOTHESIS, or UNKNOWN.
5. Give every FACT a source reference.
6. Record research questions and their status.
7. Define at least two wedge candidates.
8. Define one smallest manual test.
9. Run the existing `render-case` and `review-case` commands.
10. Record what ACDIS handled well, poorly, or could not express.

## Operating rules

- Use placeholder material only in the template file.
- Keep all pilot work inside this directory until real research begins.
- Treat missing research as unknown, not as evidence of weakness.
- Do not add crawlers, APIs, AI models, scoring, databases, or automation.
- Do not use real company names, real URLs, or PetTripFinder production data.

## Output expectations

- `render-case` is for the Phase 1 case file report.
- `review-case` is for the Phase 2 competitor-comparison review report.
- The pilot should reveal where the current workflows are useful and where they are still too rigid or too manual.

## Notes to the operator

- Capture only what you can manually verify.
- Keep source references explicit for every FACT.
- Preserve the difference between observed evidence and inference.
- Leave placeholders in place until you are ready to start actual research.

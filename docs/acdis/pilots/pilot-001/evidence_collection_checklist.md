# Evidence Collection Checklist

Use this checklist manually while preparing the pilot.

## Competitor and page coverage

- [ ] Competitor homepage
- [ ] Category page
- [ ] Location page
- [ ] Listing or profile page
- [ ] Freshness indicators
- [ ] Structured fields
- [ ] Verification signals
- [ ] Monetization methods
- [ ] User workflow
- [ ] Geographic coverage

## Capture and provenance

- [ ] Source URL recorded
- [ ] Screenshot captured
- [ ] Saved page archived
- [ ] PDF saved when relevant
- [ ] Useful excerpt captured
- [ ] Notes recorded
- [ ] Unresolved unknowns marked clearly

## Discipline checks

- [ ] FACT has a source reference
- [ ] Inference is labeled as inference
- [ ] Hypothesis is labeled as hypothesis
- [ ] UNKNOWN is preserved as unknown
- [ ] Do not promote inference into fact
- [ ] Do not invent missing evidence
- [ ] Do not collapse unknowns into conclusions

## Recording reminders

- Use explicit evidence IDs.
- Keep observations separate from source material.
- Preserve the operator's exact wording when possible.
- Do not add any AI-generated competitor judgments.

## The hash of the release
bundle_sha256 = bundle_digest(file_hashes(site_dir)): sorted Path walk of every regular file under site/ (post-move; BUILD_INTERNAL_PREFIXES written outside site/), sha256 of "relpath sha" lines joined by "\n". Bound: bundle manifest :971 → global manifest :152 → auth :157 → record :615 → deployment_state. DA.verify_bundle_directory re-derives it. The per-market assembler's bundle_hash (assemble_netlify_bundle :226-239) is a DIFFERENT formula and is not bound. Policy-package hash uses content_sha256 (normalised); every other hash is raw bytes.
